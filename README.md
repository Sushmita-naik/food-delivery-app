# 🍔 Food Delivery Web Application

A full-stack Food Delivery Web Application built using **Flask (Python)**, **SQLite**, **HTML**, and **CSS**.  
This project allows users to register, log in, browse restaurants, add food items to cart, place orders, and view receipts.

---

## 🚀 Features

- 👤 User Registration & Login system
- 🔐 Forgot password page
- 🍽️ Restaurant listing
- 📋 Food menu system
- 🛒 Add to cart functionality
- 💳 Payment page simulation
- 📦 Order placement system
- 🧾 Receipt generation
- 📊 Order history dashboard

---

## 🛠️ Tech Stack

- Frontend: HTML, CSS
- Backend: Python (Flask)
- Database: SQLite
- Version Control: Git & GitHub
